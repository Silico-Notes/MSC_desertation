# Future Work: Modern Reanalysis Plan

The primary objective of this repository is the preservation and documentation of the historical MSc thesis workflow. Modernization was explicitly deferred to maintain a scientifically honest portfolio of the original work.

Should this project be modernized in the future, the following roadmap is proposed to ensure full reproducibility and adherence to contemporary bioinformatics standards:

## 1. Modern RNA-seq Reanalysis
- Transition from the historical alignment-based approach (HISAT2 -> StringTie) to a modern pseudoalignment quantification (e.g., **Salmon** or **Kallisto**).
- Replace manual GUI-based downstream tools (ShinyGO, Cytoscape) with programmatic equivalents (e.g., **clusterProfiler** in R) for Gene Ontology and KEGG pathway enrichment.

## 2. Workflow Automation & Containerization
- Implement a structured workflow manager such as **Snakemake** or **Nextflow**.
- Utilize **Conda** environments or **Docker/Singularity** containers to rigorously pin all software versions, avoiding the "works on my machine" problem inherent in manual GUI tools.

## 3. Updated Annotation
- Update to the latest GENCODE or Ensembl reference transcriptomes.
- Programmatically map transcripts to genes using the latest `biomaRt` or GTF files, replacing the historical manual filtering for `protein_coding` biotypes.

## 4. Reproducibility Validation
- Execute the modern pipeline end-to-end starting from raw SRA FASTQ files.
- Ensure the pipeline can be identically run by any researcher strictly from the codebase.

## 5. Comparison with Historical Results
- Compare the DEGs generated by the modern pipeline against the rigorously recovered historical threshold of 521 genes.
- Statistically evaluate whether the updated quantification and annotation fundamentally shift the biological interpretation (e.g., the previously identified hub genes like CDK1, FN1, ITGB1).
